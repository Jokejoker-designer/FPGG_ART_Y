# R4 design contract — Bộ nhớ + Mô hình

| Field | Decision |
| --- | --- |
| Screen job | Show how one interaction retrieved a memory, then which model stages ran. |
| Primary user and action | Researcher: follow funnel → selected episode → memory events; then layer waterfall. |
| Content hierarchy | Source pill → funnel / pipeline → selected episode or layer card → events. |
| Navigation | Sidebar keys 7/8. Episode → model context link. Event → waveform tab only (no invented cycle). |
| Visual language | Existing Panel/Kpi/Funnel/Waterfall tokens. No 800k-node graph. |
| Required states | No retrieval; no model events; DDR occupancy awaiting (no occupancy source). |
| Responsive | Funnel + card stack below 1280; two-column at 1440. |
| Evidence used | Fixture retrieval + memory + modelEvents. SPEC §15–16, §8.1 funnel/waterfall. |
| Forbidden | BOARD-stamped cue table, sin() density, invented cue words, dim=128, MemoryGrid of fake cells. |
| Acceptance | Funnel from recorded stages; decision episode from selectedEpisodeId; model stages from modelEvents; SYNTHETIC badges; no gradient/thought claims. |
