# Design contract — R2 Dữ liệu vào + Biểu diễn

| Field | Decision |
| --- | --- |
| Screen job | Show how text became bytes, then how those bytes became 32-d state. |
| Primary action | Select a byte; toggle trước/sau học. |
| Hierarchy | Recorded sentence → byte strip → drawer + barcode; then heatmap → facts → 2D illustration. |
| Forbidden | Word-token IDs, BOARD table, next-token ranking, semantic dim names, "ý nghĩ". |
| Acceptance | Playwright R2 spec green at 1440 and 1280; tsc/build 0. |
