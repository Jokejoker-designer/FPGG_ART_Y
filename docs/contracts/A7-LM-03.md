## Live hypotheses

1. **CONFIRMED as the isolation class (netlist):** `dHid[0:63]` (and sibling scratch `dY`/`dH`/`n1_last`/`a_last`) were inferred as RAMS64E. Forced `ram_style = "registers"`. OOC post-synth and post-route funcsim now match the oracle (`xor=255` `add=2943381` `wr=20544`).
2. **LOCKED / silicon-supported:** `weight_bram25k` is an explicit READ_FIRST template. Full-FPGA isolation bit `C98B…23D1` one-full matches oracle on board. XPM/primitive is not required for this gate.
3. **REJECTED as primary:** UART, upload, write-count, 100 MHz wrapper timing.

Previous blocker: contract said `0x31 → 0xA0` but TX had no `cmd_pred` branch, so weight readback was dead. That path is now `0x31 → 0xA4`.
