## Purpose

First **100,352-parameter DDR-resident persistent-weight, FPGA-updated autoregressive Transformer**.

This is the first authoritative trainable model whose **persistent W lives in DDR**, not on-chip BRAM. LM-03 remains the BRAM control baseline and is not redesigned.

## Revision R5 (2026-08-18) — repaired hardware + bounded quality claim

R5 was defined after root-cause isolation but **before** its confirmation oracle or board run. It keeps geometry and `law_id=lm05-signsgd-v1` unchanged and does not overwrite FAIL/R2/R3/R4 evidence.

Two implementation defects are repaired:

1. synchronous ping/pong BRAM reads receive a full address-prime cycle before row 0 is captured for DDR dump;
2. every token re-enters layernorm sum/variance/scale instead of reusing token-0 statistics.

R5 does **not** retry 8-way contextual retrieval. Its bounded quality question is whether the same FPGA update law can adapt the same initial checkpoint to distinct requested target tokens on disjoint train/held-out prefixes. Separate runs start from the same seed for each target; the dominant output must follow the requested target, and final weight SHA values must differ across targets.

This permits only the claim `counterfactual target-switch online adaptation`. It does not grant 8-way contextual retrieval, open-domain language modeling, or erase R3/R4.
